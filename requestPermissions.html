🎤 Microphone Permission Required

Vision Agent needs microphone access to enable voice input. Click the button below to request permission.

If permission is denied:
  1. Click the lock/padlock icon in Chrome's address bar
  2. Find "Microphone" and change it to "Allow"
  3. Or go to: chrome://settings/content/microphone
  4. Make sure "Sites can ask to use your microphone" is enabled
  5. Remove this extension from the "Not allowed" list if present
